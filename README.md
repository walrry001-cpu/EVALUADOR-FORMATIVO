# Evaluador Formativo — 5.° "E"
I.E. N.° 82019 "La Florida del Inca" · Cajamarca · Prof. Walter Rodrigo Arribasplata Chavarry

Aplicación web (un solo archivo `index.html`, funciona sin internet y se puede instalar en el celular).

## Novedades de esta versión
- 29 estudiantes, en orden alfabético por apellido (N.° 1 al 29).
- Examen **Fila A** y **Fila B** (cada uno con 5 preguntas base + 1 adicional), guardados juntos para el mismo tema y fecha.
- Pantalla para asignar a cada estudiante A o B (botones Todos A, Todos B, Limpiar); la asignación se recuerda.
- Informe PDF y Registro separados por fila, con resumen de C / B / A / AD.
- Pendientes por evaluación concreta (tema y fecha), sin etiqueta permanente en la asistencia.
- Corregida la pestaña "Copia de seguridad".

## Publicar en GitHub Pages
1. Crea un repositorio y sube **todos** los archivos de esta carpeta (`index.html`, `manifest.json`, `sw.js`, `favicon.ico`, `icons/`).
2. En *Settings → Pages* elige *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
3. Abre la dirección que GitHub te indique y, en el celular, usa "Agregar a pantalla de inicio".

> Los datos se guardan en el navegador de cada dispositivo. Descarga una copia de seguridad desde la pestaña correspondiente.
> Aviso: la lista de nombres está dentro del HTML; si el repositorio es público, los nombres serán visibles.
